# Goethe-Zertifikat A2 — 試験概要

CEFR の **A2(基礎)** レベルを証明する Goethe-Institut の公式ドイツ語試験。
4技能(**Hören** 聞く / **Lesen** 読む / **Schreiben** 書く / **Sprechen** 話す)を測定し、世界共通の基準で実施・採点される。

> このリポジトリのゴール: **最短で A2 合格**。まず構成・配点を把握し、出題形式に沿って対策する。

- **対象:** 成人。青少年版は *A2 Fit in Deutsch*(12〜16歳、同構成)。
- **推奨学習時間:** 約200〜350時間(目安)。

---

## 証明できること(CEFR A2)

- 身近な事柄(個人情報・家族・買い物・仕事・周囲の環境など)に関する、よく使われる文や表現を理解できる。
- 簡単で日常的な場面で、なじみのある話題について情報をやり取りできる。
- 自分の経歴や身の回りのことを簡単に説明できる。

---

## モジュール構成

| モジュール | 時間 | 構成 | 内容 |
|---|---|---|---|
| 🎧 **Hören**(聞く) | 約30分 | 4 Teile | ラジオ放送、会話、留守番電話メッセージ、アナウンス |
| 📖 **Lesen**(読む) | 約30分 | 4 Teile | 短いテキスト、新聞記事・広告・掲示など(頻出語彙) |
| ✍️ **Schreiben**(書く) | 約30分 | 2 Teile | Teil 1: **SMS**(20〜30語・親しい相手へ非公式、du 形) / Teil 2: メール(約40語・3つのポイントを必ず網羅) |
| 🗣️ **Sprechen**(話す) | 約15分 | 3 Teile(ペア) | ① 相手に個人的な質問をする/答える ② 自分や自分の生活について話す ③ 相手と一緒に何かを計画する |

全試験時間は約 **1時間45分**(筆記90分 + 口述約15分、休憩除く)。

---

## 配点・合格基準

- 満点 **100点** = 筆記 **75点**(Lesen + Hören + Schreiben) + 口述 **25点**(Sprechen)。
- 合格は **60点(60%)以上**、かつ **筆記45点以上・口述15点以上**、全モジュール受験が条件。

---

## 出題範囲(テーマ・語彙)

日常生活(Alltag)が中心。A2 は「よく使う表現で簡単な情報交換・描写ができる」レベル。

- 個人情報・自己紹介(Person / Vorstellung)
- 家族・人間関係(Familie)
- 住居・身の回り(Wohnen / Umgebung)
- 買い物・食事(Einkaufen / Essen und Trinken)
- 仕事・学習(Arbeit / Beruf / Lernen)
- 地域・移動・旅行(Ort / Reisen / Verkehr)
- 時間・予定・約束(Zeit / Termine)
- 健康・身体(Gesundheit / Körper)
- 余暇・趣味(Freizeit / Hobbys)

## やっておくべき文法(A2)

> ゲーテ試験に**独立した文法問題は無い**。文法は Schreiben / Sprechen で間接評価される。A1 の文法(現在形・話法の助動詞・Perfekt 入門・Nom/Akk など)は前提とし、以下を**追加**で固める。

**動詞・時制**
- [ ] Perfekt の完全運用(規則・不規則の過去分詞を正確に)
- [ ] 過去形 Präteritum:`war, hatte` + 話法助動詞 `konnte, musste, wollte`
- [ ] 再帰動詞:`sich freuen, sich treffen` → `Ich **freue mich**.`

**格(A2の山場)**
- [ ] 3格(Dativ):`dem/der/dem/den` + 複数 `-n`
- [ ] Dativ動詞:`helfen, gefallen, danken, gehören` → `Das Buch gefällt **mir**.`
- [ ] 3格+4格の併用:`Ich gebe **dir das Buch**.`
- [ ] **Wechselpräpositionen**(3/4格)`in, an, auf, über …`:`Wo?`→3格 / `Wohin?`→4格
- [ ] 3格支配の前置詞:`seit, bei, nach, zu, von, mit, aus`

**形容詞**
- [ ] 比較・最上級:`groß – größer – am größten` / `so … wie` / `… als`
- [ ] 形容詞の格変化(入門):`ein **guter** Film` / `das **kleine** Kind`

**文の組み立て**
- [ ] 副文(動詞が文末):`weil, dass, wenn, ob` → `Ich bleibe zu Hause, **weil** ich krank **bin**.`
- [ ] 接続副詞:`deshalb, trotzdem, dann`
- [ ] 語順 TeKaMoLo(時→理由→様態→場所)の意識

**待遇・その他**
- [ ] 接続法II(丁寧・願望):`würde, könnte, hätte, wäre + gern` → `Ich **hätte gern** …` / `**Könnten** Sie …?`
- [ ] 序数・日付:`am **dritten** Mai`
- [ ] 2格(Genitiv)入門 / `von + 3格` での言い換え

---

## 対策のポイント(A2 最短合格に向けて)

- **形式慣れが最重要**: 各モジュールの Teil 構成は固定。公式 Modellsatz / Übungssatz で本番形式を反復する。
- **筆記75点の取りこぼしを防ぐ**: Schreiben Teil 2 は「3つのポイントを全て書く」ことが採点要件。形を整えれば得点しやすい。
- **Sprechen はペア練習**: 質問→応答→計画の型を準備しておく。
- **語彙は頻出テーマ別に**: Goethe 公式 Wortliste A2 の基本語を優先。
