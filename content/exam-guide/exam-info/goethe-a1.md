# Goethe-Zertifikat A1: Start Deutsch 1 — 試験概要

CEFR の **A1(入門)** レベルを証明する Goethe-Institut の公式ドイツ語試験。
4技能(**Hören** 聞く / **Lesen** 読む / **Schreiben** 書く / **Sprechen** 話す)を測定し、世界共通の基準で実施・採点される。

- **対象:** 成人(16歳〜推奨)。青少年版は *Fit in Deutsch 1*。
- **推奨学習時間:** 約80〜200時間。
- **用途:** 配偶者ビザ(家族呼び寄せ)の語学証明などにも使われる。

---

## 証明できること(CEFR A1)

- 日常のなじみのある表現や簡単な文を使える。
- 自己紹介ができ、家族・買い物・仕事などについての基本的な質問に答えられる。
- 相手がゆっくり明瞭に話せば、日常会話を理解できる。

---

## モジュール構成

| モジュール | 時間 | 構成 | 内容 |
|---|---|---|---|
| 🎧 **Hören**(聞く) | 約20分 | 3 Teile | 日常の短い会話、電話メッセージ、公共アナウンス |
| 📖 **Lesen**(読む) | 約25分 | 3 Teile | 短いメモ・メール、広告、掲示・標識 |
| ✍️ **Schreiben**(書く) | 約20分 | 2 Teile | Teil 1: フォーム記入 / Teil 2: 日常の短い個人的メッセージ(メール) |
| 🗣️ **Sprechen**(話す) | 約15分 | 3 Teile(グループ) | ① 自己紹介＋アルファベット/数字のスペル ② 相手に質問する ③ 何かを依頼する |

筆記3モジュール(Hören + Lesen + Schreiben)の所要時間は合計約65分。Sprechen は別枠・グループ形式で実施される。

---

## 配点・合格基準

- 満点 **100点** = 4モジュール **各25点 × 4**(筆記75点 + 口述25点)。
- 合格は全体で **60点(60%)以上**、かつ全モジュール受験が条件。
- 筆記(75点)で **35点未満**だと、口述が満点でも合計60点に届かない(=実質的な筆記の下限)。

---

## 出題範囲(テーマ・語彙)

日常生活(Alltag)が中心。A1 は「決まり文句＋単純文」レベル。

- 個人情報・自己紹介(Person / Vorstellung)
- 家族・人間関係(Familie)
- 住居・身の回り(Wohnen / Umgebung)
- 買い物・食事(Einkaufen / Essen und Trinken)
- 仕事・学習(Arbeit / Lernen)
- 地域・移動(Ort / Verkehr)
- 時間・予定(Zeit / Termine)
- 余暇・趣味(Freizeit / Hobbys)

---

## やっておくべき文法(A1)

> ゲーテ試験に**独立した文法問題は無い**。文法は Schreiben / Sprechen の中で間接的に評価されるので、「知っている」より「正しく使える」状態を目指す。

**動詞・時制**
- [ ] 現在形(規則・不規則):`ich wohne` / `du sprichst` / `er fährt`
- [ ] `sein` / `haben`:`ich bin` / `ich habe`
- [ ] 話法の助動詞:`können, müssen, möchten, wollen, dürfen` → `Ich kann Deutsch sprechen.`
- [ ] 分離動詞:`aufstehen` → `Ich stehe um 7 Uhr **auf**.`
- [ ] 命令形(Sie / du):`Kommen Sie!` / `Komm!`
- [ ] 完了形(Perfekt 入門):`haben/sein + 過去分詞` → `Ich **habe** Pizza **gegessen**.` / `Ich **bin** nach Berlin **gefahren**.`

**名詞・格・冠詞**
- [ ] 定冠詞・不定冠詞・否定の `kein`:`der/ein/kein`
- [ ] 名詞の複数形
- [ ] 1格(Nominativ)・4格(Akkusativ):`Ich habe **einen** Hund.`
- [ ] 所有冠詞:`mein, dein, sein, ihr` → `Das ist **meine** Schwester.`
- [ ] 人称代名詞(1・4格):`ich/mich, du/dich, er/ihn …`

**文の組み立て**
- [ ] 平叙文の語順(動詞は2番目)
- [ ] 疑問文:W疑問文(`wer/was/wo/wann/wie/warum`)/ Ja-Nein疑問文(動詞が先頭)
- [ ] 枠構造(Satzklammer):`Ich **möchte** ein Eis **kaufen**.`
- [ ] 並列接続詞:`und, oder, aber, denn`

**その他**
- [ ] 基本前置詞:`in, auf, mit, für …` + 時の表現 `am Montag / um 8 Uhr / im Mai`
- [ ] 数・時刻・日付・曜日

---

## 対策のポイント

- **形式慣れが最優先**: 各 Teil の構成は固定。公式 Modellsatz で本番形式を反復する。
- **語彙はテーマ別に**: Goethe 公式 Wortliste A1 の基本語を優先して覚える。
- **Sprechen**: 「自己紹介→質問→依頼」の型を暗記レベルで準備する(グループ形式)。
