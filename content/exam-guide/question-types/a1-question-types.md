# Goethe-Zertifikat A1 — 問題形式の詳細解説

各モジュール(Hören / Lesen / Schreiben / Sprechen)で「具体的にどんな問題が出るか」をパート(Teil)ごとに解説する。
全体概要は [`../exam-info/goethe-a1.md`](../exam-info/goethe-a1.md)、解答つきの実問題は [`a1-practice.md`](./a1-practice.md) を参照。

- 構成: 筆記3モジュール(Hören・Lesen・Schreiben、計約65分)+ Sprechen 約15分(別枠)
- 満点 **100点** = 4モジュール **各25点 × 4**(筆記75点 + 口述25点)
- 合格は **60点(60%)以上**、かつ全モジュール受験が条件
- 例題は公式 Modellsatz/Übungssatz に基づく代表例(本番の題材は毎回変わる)

> 出典:Goethe-Institut 公式 *Prüfungsziele · Testbeschreibung A1 (Start Deutsch 1)* および *Modellsatz*。

---

## 🧭 試験の流れ・時間配分・採点

### 時間と配点

| モジュール | 時間 | 配点 | 割合 |
|---|---|---|---|
| Hören(聞く) | 約20分 | 25点 | 25% |
| Lesen(読む) | 25分 | 25点 | 25% |
| Schreiben(書く) | 20分 | 25点 | 25% |
| Sprechen(話す) | 15分 | 25点 | 25% |
| **合計** | 約80分 | **100点** | 100% |

筆記3つ(約65分)はまとめて実施し、Sprechen は別枠。筆記と口述は通常**14日以内**に行われる。

### 採点の仕組み(素点 → 25点換算)

- **各モジュールは25点満点**に揃えられる。筆記3技能は内部の素点(Messpunkte)最大15点を **×約1.67** で25点に換算する(A2 は項目数20で ×1.25)。
  - **Hören**:15項目 × 1点 = 最大15 → 25点に換算
  - **Lesen**:15項目 × 1点 = 最大15 → 25点に換算
  - **Schreiben**:Teil 1(5点)+ Teil 2(10点)= 最大15 → 25点に換算
  - **Sprechen**:Teil 1–3 を採点 → 25点
- Hören / Lesen は**部分点なし**(正答1点/誤答0点、空欄でも減点なし)。**必ず全問マーク**する。
- 合格 = **総合60点(60%)以上 + 全モジュール受験**。**筆記で35点未満だと、口述が満点でも合格に届かない**(=実質的な筆記の下限)。
- **再受験は試験全体のみ**(モジュール単位の再受験は不可)。

### 成績評価(Prädikat・100点満点)

| 点数 | 評価 |
|---|---|
| 100–90 | sehr gut(優) |
| 89–80 | gut(良) |
| 79–70 | befriedigend(可) |
| 69–60 | **ausreichend(合格ライン)** |
| 59–0 | nicht bestanden(不合格) |

## 🎧 Hören(聞く)— 約20分 / 3 Teile / 15項目

| Teil | 項目数 | 聞く素材 | 形式 | 再生回数 |
|---|---|---|---|---|
| 1 | 6 | 日常の短い会話・アナウンス | 3択(**写真** a/b/c) | **2回** |
| 2 | 4 | 公共のアナウンス(Durchsage) | **Richtig / Falsch** | **1回** |
| 3 | 5 | 留守番電話・電話メッセージ等 | 3択(a/b/c) | **2回** |

**Teil 1 — 写真3択(2回)**
短い会話を聞き、質問(例:「Was kauft die Frau?」)に合う写真を3枚から選ぶ。値段・時刻・物・人などが問われる。
- 例:会話で「Das Brot kostet 2 Euro 50.」→ 値段が書かれた3枚の写真から選ぶ。
- コツ:**3枚の写真を音声前に見て**「何が違うか(値段か?物か?時刻か?)」を把握しておく。

**Teil 2 — Richtig / Falsch(1回だけ)**
デパート・駅・空港・バス車内などの**館内放送/車内放送**を聞く。問題文が放送内容と合っていれば Richtig、違えば Falsch。
- 例:放送「Der Zug nach München fährt heute von Gleis 9.」/ 問題文「Der Zug fährt von Gleis 5.」→ **Falsch**。
- 注意:**1回しか流れない**ので集中が必要。数字(ホーム番号・時刻・金額)の言い換え/すり替えが狙われる。

**Teil 3 — 留守電3択(2回)**
留守電メッセージなどを聞き、a/b/c から選ぶ。時間・場所・予定の聞き取りが中心。
- 落とし穴:`nicht / kein / leider` の否定、`erst / schon / später` などの時間表現。

## 📖 Lesen(読む)— 約25分 / 3 Teile / 15項目

| Teil | 項目数 | 読む素材 | 形式 |
|---|---|---|---|
| 1 | 5 | 短い私的テキスト(メール・手紙) | **Richtig / Falsch** |
| 2 | 5 | 広告・ウェブ情報 | 2択(a / b) |
| 3 | 5 | 掲示・標識(Schilder) | **Richtig / Falsch** |

**時間配分の目安(計25分)**:各 Teil ≈ 7分 + 転記/見直し ≈ 4分。

**Teil 1 — メールを読んで Richtig/Falsch**
友人・家族からの短いメール2通を読み、各問題文が内容と一致するか判定する。
- 問題文のキーワードを本文から探し、**合致(Richtig)か矛盾(Falsch)か**を確認。書かれていない=推測しない。

**Teil 2 — 広告マッチング(a/b の2択)**
ある状況(例:「あなたは電車でベルリンへ行きたい」)に対し、提示された**2つの広告/サイト a と b** のうち合う方を選ぶ。
- 例:「日曜にケーキを買いたい」→ 営業時間や商品の記載を見て a か b を選ぶ。
- 注意:キーワード(**曜日・場所・値段・営業時間**)の照合がカギ。条件を1つでも満たさない方は外す。

**Teil 3 — 標識を読んで Richtig/Falsch**
語学学校・郵便局・駅・レストラン・バス停などの**掲示や貼り紙**を読み、問題文の真偽を判定。
- 短文でも `nur / geschlossen / ab / bis / außer` などの語が真偽を左右する。

## ✍️ Schreiben(書く)— 約20分 / 2 Teile

| Teil | 課題 | 内容 | 素点 |
|---|---|---|---|
| 1 | フォーム記入(Formular) | 空欄 **5つ** を埋める | 5点 |
| 2 | 短いメッセージ(メール) | **3つのポイント**を各1〜2文、計約30語 | 10点 |

> 素点は Teil 1 + Teil 2 = 最大15点。これを**25点満点に換算**する(上の採点表を参照)。

**時間配分の目安(計20分)**:Teil 1 ≈ 7分 / Teil 2 ≈ 10分 / 見直し ≈ 3分。

**Teil 1 — 申込用紙の穴埋め**
与えられた本文情報をもとに、申込書/登録フォームの欠けた **5項目**(例:人数、子どもの数、住所、支払い方法 など)を記入する。
- 本文から該当情報を拾うだけ。**つづり・数字・日付の形式**を正確に。空欄を残さない。

**Teil 2 — 約30語のメール**
指示された3点について、それぞれ1〜2文書く。
- 例:観光案内所へ「①なぜ書いているか ②文化プログラムの情報がほしい ③ホテルの住所を教えてほしい」。
- 採点:内容3点 +(伝達・形式)= 10点。**3点すべてに必ず触れる**ことが最重要(欠けると大きく減点)。

**使えるフレーズ**
- 書き出し:`Liebe Anna,` / `Hallo,`(親しい相手)/ `Sehr geehrte Damen und Herren,`(公的な宛先)
- 結び:`Liebe Grüße` / `Viele Grüße` / `Mit freundlichen Grüßen`
- 用件:`Ich schreibe Ihnen, weil …` / `Ich möchte gern …` / `Können Sie mir bitte … schicken?` / `Bitte schicken Sie mir die Adresse.`

## 🗣️ Sprechen(話す)— 約15分 / 3 Teile / **グループ試験(最大4名)**

**準備時間なし**。カードを使って進行する。試験官は通常2名。

**Teil 1 — 自己紹介(Sich vorstellen)**
7つのキーワードについて自分のことを話す:**Name / Alter / Land / Wohnort / Sprachen / Beruf / Hobby**。
そのあと、**単語のスペル(buchstabieren)** と **数字(例:電話番号)を言う** 課題がある。
- 型:`Ich heiße …` / `Ich bin … Jahre alt.` / `Ich komme aus …` / `Ich wohne in …` / `Ich spreche …` / `Ich bin … von Beruf.` / `Mein Hobby ist …`
- スペル:`Mein Name ist Tomita: T–O–M–I–T–A.`

**Teil 2 — 質問する/答える(Um Informationen bitten)**
テーマ別の**単語カード**を引き、その語を使って相手に質問を作り、相手の質問にも答える。
- テーマ例:食べ物・飲み物(Frühstück, Lieblingsessen, Brot…)/ 買い物(Zeitung, Obst, Buch…)。
- 例:カード「Brot」→「Essen Sie gern Brot?」/ 相手が答える。
- 型:`Essen/Trinken Sie gern …?` / `Haben Sie …?` / `Wann/Wo …?`

**Teil 3 — 依頼する/反応する(Bitten formulieren)**
**絵カード**を引き、その物について丁寧な依頼を作り、相手の依頼に応じる。
- 例:絵「Bleistift(鉛筆)」→「Können Sie mir bitte den Bleistift geben?」→ 相手「Ja, hier bitte.」
- 物の例:Flasche, Stuhl, Apfel, Radio, Tasche など。
- 型(依頼):`Können Sie mir bitte … geben?` / `Geben Sie mir bitte …` (応答)`Ja, hier bitte.` / `Natürlich.`
