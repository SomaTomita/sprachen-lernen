# ドイツ語文法 04 — 名詞の複数形(Plural)

[01 人称代名詞](01-personalpronomen-sein.md)・[02 動詞の現在人称変化](02-verben-praesens.md)・[03 名詞の性](03-nomen-genus.md)に続く第4回。テーマは**名詞の複数形(Plural)**。英語は語尾に `-s` を足すだけだが、ドイツ語は5つのパターンがある。**ただし朗報が一つ:複数形では性が消える。** `der/die/das` を気にせず、**複数の冠詞はいつでも `die` の1つだけ**。

- ゴール:① **複数はすべて `die`** だと体に入れる ② 5つの複数パターンを区別できる ③ **性と語尾から複数形を予測**できる ④ 単数のみ/複数のみの名詞を知る
- いちばん大事な心構え:[03](03-nomen-genus.md) で「名詞は冠詞とセットで覚える」と言ったが、ここでさらに **複数形もセットで覚える**。`der Hund`(犬)なら **`der Hund / die Hunde`** までを1セットにする。複数形は規則だけでは当てきれず、**約2割は例外**だから、単語帳に最初から書き込むのが結局いちばん速い。

> 🔗 **練習問題**: [このレッスンの練習問題を解く](apps/grammar-exercises/?lesson=04)(別ページ・採点と解説つき)

> 出典:初級ドイツ語文法の動画講座(名詞の複数形)を学習用に整理・補正したもの。例語はスライドに基づき、標準的なドイツ語として複数形を確認した。補足の単語は本リポジトリの単語データ(A1・A2)から性を確認し、複数形を付けて追加している。

---

## 🎯 大原則 — 複数は全部 `die`、パターンは5つ

### まず:複数形に性はない

単数では3つに分かれていた性が、複数では**全部 `die` に合流**する。

| 単数 | → 複数 |
|---|---|
| **`der`** Mann(男性) | **`die`** Männer |
| **`die`** Frau(女性) | **`die`** Frauen |
| **`das`** Kind(子ども) | **`die`** Kinder |

> つまり複数形の冠詞は迷う余地がない。**`die` 一択。** 悩むのは「語の形がどう変わるか」だけ。

### 変わるのは語尾(と母音)

複数形は基本「単数に何かを足す/母音を変える」で作る。足し方は次の **5パターン**。

| パターン | やること | 例 |
|---|---|---|
| **A** | 変化なし(または母音にウムラウトだけ) | das Fenster → die Fenster / der Bruder → die Br**ü**der |
| **B** | 語尾に **`-e`**(±ウムラウト) | der Brief → die Brief**e** / der Sohn → die S**ö**hn**e** |
| **C** | 語尾に **`-er`**(母音は原則ウムラウト) | das Kind → die Kind**er** / das Buch → die B**ü**ch**er** |
| **D** | 語尾に **`-(e)n`**(ウムラウトなし) | die Blume → die Blume**n** / die Frau → die Frau**en** |
| **E** | 語尾に **`-s`**(ウムラウトなし) | das Auto → die Auto**s** / die Party → die Party**s** |

> **ウムラウトできる母音は `a o u au` だけ**(→ `ä ö ü äu`)。`e` や `i` は点が付かない。だから `der Brief → die Briefe`(ウムラウトなし)、`der Gast → die Gäste`(a→ä)。

---

## 🔁 A — 変化なし(または ¨ だけ)

**`-er` / `-el` / `-en` で終わる男性・中性名詞**と、**中性の縮小形 `-chen` / `-lein`** が中心。形はそのまま、ウムラウトできる語は母音だけ変わる。

| 単数 | 複数 | 意味 |
|---|---|---|
| der Wagen | die Wagen | 車 |
| das Fenster | die Fenster | 窓 |
| das Mittel | die Mittel | 手段・方法 |
| der Lehrer | die Lehrer | 教師 |
| der Schüler | die Schüler | 生徒 |
| der Computer | die Computer | コンピューター |
| der Koffer | die Koffer | スーツケース |
| der Löffel | die Löffel | スプーン |
| das Zimmer | die Zimmer | 部屋 |
| das Messer | die Messer | ナイフ |
| das Mädchen | die Mädchen | 女の子(`-chen`) |
| das Brötchen | die Brötchen | 小型パン(`-chen`) |

**ウムラウトが付くタイプ**(母音が `a o u au`):

| 単数 | 複数 | 意味 |
|---|---|---|
| der Bruder | die Br**ü**der | 兄弟 |
| der Vater | die V**ä**ter | 父 |
| die Mutter | die M**ü**tter | 母 ※女性だがこのAグループはMutter/Tochterのみ |
| die Tochter | die T**ö**chter | 娘 |
| der Apfel | die **Ä**pfel | りんご |

> **見分け方:** `-er / -el / -en` で終わっていたら「たぶん変化なし」と当たりをつける。ただし母音にウムラウトが付くかどうかは1語ずつ覚える(`der Bruder → Brüder` は付く、`der Lehrer → Lehrer` は付かない)。

## ➕ B — 語尾に `-e`

**多くの男性名詞**と一部の中性・女性名詞。男性・中性は**ウムラウトが付いたり付かなかったり**、**女性は必ずウムラウトが付く**。

| 単数 | 複数 | 意味 |
|---|---|---|
| der Berg | die Berge | 山 |
| der Brief | die Briefe | 手紙 |
| der Monat | die Monate | 月(暦の) |
| der Tag | die Tage | 日 |
| der Tisch | die Tische | 机 |
| der Hund | die Hunde | 犬 |
| der Beruf | die Berufe | 職業 |
| das Jahr | die Jahre | 年 |
| das Brot | die Brote | パン |

**ウムラウトが付くタイプ:**

| 単数 | 複数 | 意味 |
|---|---|---|
| der Gast | die G**ä**ste | 客 |
| der Sohn | die S**ö**hne | 息子 |
| der Stuhl | die St**ü**hle | 椅子 |
| der Zug | die Z**ü**ge | 電車 |
| der Baum | die B**äu**me | 木 |
| die Hand | die H**ä**nde | 手(女性) |
| die Stadt | die St**ä**dte | 町(女性) |
| die Nacht | die N**ä**chte | 夜(女性) |

> **女性名詞でB(`-e`)になるものは少数だが、なるときは必ずウムラウト**:`Hand→Hände`, `Stadt→Städte`, `Nacht→Nächte`, `Wand→Wände`, `Maus→Mäuse`。数が少ないので丸ごと覚えてよい。

## 🧒 C — 語尾に `-er`

**多くの中性名詞**と少数の男性名詞。**母音が `a o u au` なら必ずウムラウト**が付く(`e i` は付かない)。**女性名詞はこのパターンに入らない。**

| 単数 | 複数 | 意味 |
|---|---|---|
| das Kind | die Kinder | 子ども |
| das Ei | die Eier | 卵 |
| das Bild | die Bilder | 絵・写真 |
| das Lied | die Lieder | 歌 |
| das Buch | die B**ü**cher | 本 |
| das Land | die L**ä**nder | 国 |
| das Haus | die H**äu**ser | 家 |
| das Glas | die Gl**ä**ser | グラス |
| das Dorf | die D**ö**rfer | 村 |
| das Wort | die W**ö**rter | 単語 |
| das Fahrrad | die Fahrr**ä**der | 自転車 |
| der Mann | die M**ä**nner | 男性 |
| der Wald | die W**ä**lder | 森 |

> **コツ:** Cパターンは「中性名詞+1音節」に多い(`Kind, Buch, Land, Haus, Ei…`)。ウムラウトできる母音があれば**ほぼ自動で点が付く**と思ってよい。

## 🔚 D — 語尾に `-(e)n`(ウムラウトなし)

**女性名詞の大多数**がこれ。さらに **n変化の男性名詞**(`-ist` の人など)や一部の中性も。**このパターンは絶対にウムラウトが付かない。**

- 子音で終わる語 → **`-en`**(Frau → Frauen)
- `-e` で終わる語 → **`-n`** だけ(Blume → Blumen)
- `-in`(女性職業) → **`-nen`** と n が2つ(Lehrerin → Lehrerinnen)

| 単数 | 複数 | 意味 |
|---|---|---|
| die Frau | die Frauen | 女性 |
| die Blume | die Blumen | 花 |
| die Katze | die Katzen | 猫 |
| die Schwester | die Schwestern | 姉妹 |
| die Flasche | die Flaschen | 瓶 |
| die Uhr | die Uhren | 時計 |
| die Zeitung | die Zeitungen | 新聞(`-ung`) |
| die Wohnung | die Wohnungen | 住居(`-ung`) |
| die Universität | die Universitäten | 大学(`-tät`) |
| die Adresse | die Adressen | 住所 |
| die Lehrerin | die Lehrerinnen | 女性教師(`-in → -nnen`) |
| der Student | die Studenten | 大学生(n変化) |
| der Junge | die Jungen | 少年(n変化) |
| der Mensch | die Menschen | 人間(n変化) |
| das Auge | die Augen | 目 |
| das Bett | die Betten | ベッド |

> **量で言うと最頻パターン**。女性名詞を見たら、まず「複数は `-(e)n` だろう」と当てるのが一番打率が高い。

## 🌐 E — 語尾に `-s`(ウムラウトなし)

**外来語**(英語・フランス語など)、**短縮語**、**`-a / -o / -i / -y` などの母音で終わる語**に多い。英語と同じ感覚で `-s` を足す。

| 単数 | 複数 | 意味 |
|---|---|---|
| das Auto | die Autos | 車 |
| das Foto | die Fotos | 写真 |
| das Büro | die Büros | オフィス |
| das Sofa | die Sofas | ソファ |
| das Hotel | die Hotels | ホテル |
| das Kino | die Kinos | 映画館 |
| das Handy | die Handys | 携帯電話 |
| das Baby | die Babys | 赤ちゃん |
| das Taxi | die Taxis | タクシー |
| das Ticket | die Tickets | チケット |
| die Kamera | die Kameras | カメラ |
| die Party | die Partys | パーティー |
| die Oma | die Omas | おばあちゃん |
| der Opa | die Opas | おじいちゃん |
| der Chef | die Chefs | 上司 |
| der Tee | die Tees | お茶 |

> **ドイツ語綴りに注意:** `Party → Partys`(英語の *Parties* ではない)、`Baby → Babys`、`Handy → Handys`。`-y` は **`-ys`** のまま。

## 🧭 性と語尾から複数形を予測する

[03 名詞の性](03-nomen-genus.md) で習った**性別の語尾**は、複数形の予測にも使える。**「語尾 → 性 → 複数の作り方」が一直線につながる**のがこの回の山場。

### 性別語尾のおさらい(03より)

| 性 | 代表的な語尾 |
|---|---|
| 男性 | `-ich` `-ig` `-ling` / `-er` / `-ismus` `-ist` |
| 女性 | `-heit` `-keit` `-schaft` `-ei` / `-ung` / `-e` `-ik` `-ion` `-tät` |
| 中性 | `-chen` `-lein` / `-nis` `-tum` / `-um` `-ment` |

### 語尾 → 複数形の早見

| 性 | 語尾 | 複数のなり方 | 例 |
|---|---|---|---|
| 男性 | `-ich` `-ig` `-ling` | **`-e`** | der König → die König**e** |
| 男性 | `-er` `-el` `-en` | **変化なし(±¨)** | der Fahrer → die Fahrer |
| 男性 | `-ist` | **`-en`** | der Polizist → die Polizist**en** |
| 男性 | `-ismus` | **`-ismen`** | der Organismus → die Organism**en** |
| 女性 | `-e` | **`-n`** | die Woche → die Woche**n** |
| 女性 | `-ung` `-heit` `-keit` `-schaft` `-ei` | **`-en`** | die Zeitung → die Zeitung**en** |
| 女性 | `-ion` `-tät` `-ik` | **`-en`** | die Information → die Information**en** |
| 中性 | `-chen` `-lein` | **変化なし** | das Mädchen → die Mädchen |
| 中性 | `-um`(ラテン系) | **`-um` を取って `-en`** | das Museum → die Muse**en** |
| 中性 | `-ment` | **`-e`** | das Experiment → die Experiment**e** |
| 中性 | `-nis` | **`-nisse`**(s が重なる) | das Ergebnis → die Ergebni**sse** |

> 動画のスライドでは `-ment` を `-en` とまとめていたが、標準は **`-e`**(`die Experimente`, `die Dokumente`, `die Medikamente`)。例のスライド自体も `die Experimente` になっている。本ページは正しい `-e` で統一する。

### 例で確認

**【女性】`-heit` `-keit` `-schaft` `-ung` → `-en`**

| 単数 | 複数 | 意味 |
|---|---|---|
| die Kindheit | die Kindheiten | 子供時代 |
| die Weisheit | die Weisheiten | 知恵 |
| die Kleinigkeit | die Kleinigkeiten | 小さなこと |
| die Freundschaft | die Freundschaften | 友情 |
| die Erinnerung | die Erinnerungen | 思い出 |
| die Leistung | die Leistungen | 成績 |

**【男性】`-ich` `-ig` `-ling` → `-e`**

| 単数 | 複数 | 意味 |
|---|---|---|
| der Teppich | die Teppiche | カーペット |
| der Rettich | die Rettiche | 大根 |
| der König | die Könige | 王様 |
| der Schmetterling | die Schmetterlinge | 蝶 |
| der Lehrling | die Lehrlinge | 弟子 |

**【女性】`-e` `-ion` `-tät` → `-n` / `-en`**

| 単数 | 複数 | 意味 |
|---|---|---|
| die Woche | die Wochen | 週 |
| die Stunde | die Stunden | 時間 |
| die Information | die Informationen | 情報 |
| die Region | die Regionen | 地域 |
| die Universität | die Universitäten | 大学 |
| die Realität | die Realitäten | 現実 |

**【中性】`-chen` `-lein` → 変化なし / `-um` → `-en` / `-ment` → `-e`**

| 単数 | 複数 | 意味 |
|---|---|---|
| das Mädchen | die Mädchen | 少女 |
| das Häuschen | die Häuschen | 小屋 |
| das Männlein | die Männlein | 小人 |
| das Museum | die Museen | 博物館 |
| das Experiment | die Experimente | 実験 |

## 🚫 単数しかない名詞・複数しかない名詞

### 単数しかない名詞(数えられないもの)

液体・素材・抽象概念など、**数えない名詞は複数形を持たない**。英語の *milk, money, love* と同じ感覚。

| 名詞 | 意味 | |
|---|---|---|
| der Regen | 雨 | 複数形なし |
| der Schnee | 雪 | 複数形なし |
| die Liebe | 愛 | 複数形なし |
| die Milch | 牛乳 | 複数形なし |
| das Geld | お金 | 複数形なし |
| das Mehl | 粉 | 複数形なし |
| das Obst | 果物(集合) | 複数形なし |
| das Gemüse | 野菜(集合) | 複数形なし |
| das Fleisch | 肉 | 複数形なし |
| das Gepäck | 荷物(集合) | 複数形なし |
| das Glück | 幸運 | 複数形なし |
| der Hunger | 空腹 | 複数形なし |

### 複数しかない名詞

逆に**いつも複数で使う**名詞もある。単数形が存在しない/ふつう使わない。

| 名詞 | 意味 | メモ |
|---|---|---|
| die Eltern | 両親 | 父+母で必ず2人以上 |
| die Geschwister | 兄弟姉妹 | きょうだいの総称 |
| die Leute | 人々 | 「人(単数)」は `der Mensch` を使う |
| die Ferien | (学校の)休暇 | 1日でも複数形 |
| die Kosten | 費用・経費 | 「いくらかかるか」は必ず複数 |
| die USA | アメリカ合衆国 | 州の集まり=複数。`die USA` |

> **なぜ国が複数?** アメリカは複数の州(states)の集まりだから、もともと複数で `die USA`。`die Niederlande`(オランダ=低地の集まり)も同じ理屈。

## 🧾 まとめ(早見表)

### 5パターン一覧

| パターン | 語尾 | ウムラウト | 主に | 例 |
|---|---|---|---|---|
| **A** 変化なし | (なし) | あり得る | 男性・中性の `-er/-el/-en`、中性 `-chen/-lein` | Fenster → Fenster / Bruder → Brüder |
| **B** `-e` | `-e` | あり得る(女性は必ず) | 多くの男性 | Brief → Briefe / Sohn → Söhne |
| **C** `-er` | `-er` | 母音があれば必ず | 多くの中性 | Kind → Kinder / Buch → Bücher |
| **D** `-(e)n` | `-(e)n` | **なし** | 女性の大多数・n変化男性 | Frau → Frauen / Blume → Blumen |
| **E** `-s` | `-s` | **なし** | 外来語・母音で終わる語 | Auto → Autos / Party → Partys |

### 当てる手順

1. **複数の冠詞は `die` で確定**(性は考えない)。
2. **語尾で当たりをつける**:女性 `-ung/-heit/-keit/-e` → D(`-(e)n`)、中性1音節 → C(`-er`)、外来語 → E(`-s`)、男性 `-ich/-ig/-ling` → B(`-e`)、`-er/-el/-en` → A(変化なし)。
3. **ウムラウトが付くか**は母音が `a o u au` のときだけ気にする(`e i` は無関係)。
4. **それでも不安なら暗記**(約2割は例外)。単語帳に複数形ごと書く。

| das Buch | die Bücher | 本 | C(¨) |

| die Frau | die Frauen | 女性 | D |

| die Stadt | die Städte | 町 | B(¨) |
| das Auto | die Autos | 車 | E |

## 📌 予告 — 複数3格は語尾に `-n`

複数形は冠詞こそ `die` で固定だが、**3格(Dativ)になると名詞自身の語尾に `-n` が付く**(すでに `-n` や `-s` で終わる語を除く)。次回詳しく扱うが、形だけ予告。

| 格 | 例 | メモ |
|---|---|---|
| 1格 複数 | die Kinder | そのまま |
| 3格 複数 | mit den Kinder**n** | 名詞に `-n`、冠詞は `den` |
| 3格 複数(`-s`語) | mit den Auto**s** | `-s` 語は `-n` を付けない |

> いまは「**複数3格 = 名詞のおしりに `-n`**」とだけ覚えておけば十分。

## ❌ よくある間違い・落とし穴

| ありがちなミス | 正しくは | 理由 |
|---|---|---|
| `die Mann`(複数なのに?) | `die Männer` | 複数は冠詞が `die`、語形は `-er`+ウムラウト |
| `der Kinder`(複数に der?) | `die Kinder` | **複数の冠詞はいつでも `die`**。性は消える |
| `die Autoen` / `die Auten` | `die Autos` | 外来語・母音終わりは E(`-s`) |
| `die Mädchens` | `die Mädchen` | `-chen` は変化なし。`-s` を付けない |
| `die Bücher` の母音を `Buchers` に | `die Bücher` | C は母音にウムラウト、語尾は `-er` |
| `mit den Kinder`(3格で `-n` 忘れ) | `mit den Kinder**n**` | 複数3格は名詞に `-n` を足す |
| 性だけ覚えて複数形は後回し | `der Hund / die Hunde` までを1セットで | 複数は約2割が例外。後から覚え直すと二度手間 |

> **最後にもう一度:** 複数形は「冠詞 `die` は固定 → 語尾は5パターン → ウムラウトは `a o u au` のときだけ」。規則で当たりをつけたら、**例外は単語ごと暗記**。単語帳に `単数 / 複数` を並べて書くのが、遠回りに見えていちばん速い。
