# ドイツ語文法 03 — 名詞の性(der / die / das)

[01 人称代名詞](01-personalpronomen-sein.md)・[02 動詞の現在人称変化](02-verben-praesens.md)に続く第3回。テーマは**名詞の性(Genus)**。ドイツ語の名詞はすべて **男性 `der` / 女性 `die` / 中性 `das`** のどれかに属し、これが冠詞・形容詞・代名詞の形すべてに関わる。**最初の関門だが、ここを越えれば一生迷わなくなる。**

- ゴール:① 「性は丸暗記が基本」と腹をくくる ② **意味と語尾の手がかり**で当たりをつけられる ③ 代表的な**例外**を知る
- いちばん大事な心構え:**名詞は必ず冠詞とセットで覚える。** `Hund`(犬)ではなく **`der Hund`** で覚える。意味だけ覚えて性を後回しにすると、結局あとで覚え直しになる。

> 出典:初級ドイツ語文法の動画講座(名詞の性)を学習用に整理・補正したもの。例語はスライドに基づき、標準的なドイツ語として確認した。補足の単語は本リポジトリの単語データ(A1・A2)から性を確認して追加している。

## 🎯 大原則 — 3つの性と「暗記が基本」

ドイツ語の名詞には2つの大きな特徴がある。

1. **名詞は文中でも語頭が必ず大文字**(`der Hund`, `die Universität` …)。
2. **すべての名詞に性がある**(男性・女性・中性の3つ)。

| 性 | 定冠詞 | 例 | 割合(目安) |
|---|---|---|---|
| 男性(Maskulinum) | **`der`** | `der Hund`(犬) | 約 34% |
| 女性(Femininum) | **`die`** | `die Katze`(猫) | 約 46% |
| 中性(Neutrum) | **`das`** | `das Pferd`(馬) | 約 20% |

> **残酷な事実:なぜ犬が男性名詞なのか、論理的な理由はほぼ無い。** 多くの名詞は**1語ずつ覚える**しかない。下で紹介する「見分け方」は当たる確率を上げる**補助**であって、絶対ルールではない。まずはたくさんの名詞を `der/die/das` 付きで覚え、感覚ができてから本ページの見分け方を読み返すのが効く。

### 似た仲間でも性はバラバラ

「食器」という同じカテゴリーでも、性は見事に3つに分かれる。**意味のグループと性は一致しない**ことを示す有名な例。

| ドイツ語 | 意味 | 性 |
|---|---|---|
| `der Löffel` | スプーン | 男性 |
| `die Gabel` | フォーク | 女性 |
| `das Messer` | ナイフ | 中性 |

> だからこそ「カテゴリーで覚える」ではなく「単語ごとに冠詞つきで覚える」。

## ♂ 男性名詞(der)

### 意味で決まるグループ

| グループ | 例(独) | 意味 |
|---|---|---|
| ① 生物的に男性の人 | `der Mann` / `der Junge` / `der Vater` / `der Bruder` / `der Sohn` / `der Opa` / `der Onkel` / `der Freund` | 男性 / 少年 / 父 / 兄弟 / 息子 / 祖父 / おじ / 男友達 |
| ② 職業(男性が就いているとき) | `der Lehrer` / `der Student` / `der Pilot` / `der Politiker` / `der Verkäufer` / `der Koch` / `der Youtuber` | 教師 / 大学生 / パイロット / 政治家 / 販売員 / 料理人 / ユーチューバー |
| ③ 曜日 | `der Montag` 〜 `der Sonntag` | 月曜〜日曜(**全部**男性) |
| ④ 時間帯 | `der Morgen` / `der Mittag` / `der Abend` | 朝 / 昼 / 夜 ※**例外 `die Nacht`(夜中)** |
| ⑤ 月・季節・方角 | `der Januar`… / `der Frühling` `der Sommer` `der Herbst` `der Winter` / `der Norden` `der Süden` `der Osten` `der Westen` | 12か月・四季・東西南北は**例外なく**男性 |
| ⑥ 風・天候・空から降るもの | `der Wind` / `der Sturm` / `der Taifun` / `der Föhn` / `der Regen` / `der Schnee` / `der Hagel` / `der Reif` | 風 / 嵐 / 台風 / ドライヤー(熱風) / 雨 / 雪 / 雹 / 霜 ※**例外 `die Brise`(そよ風)** |
| ⑦ 酒の種類 | `der Wein` / `der Schnaps` / `der Whisky` / `der Sekt` | ワイン / 蒸留酒 / ウイスキー / シャンパン ※**例外 `das Bier`(ビール)** |
| ⑧ 車のブランド・石・砂 | `der Toyota` / `der BMW` / `der VW` / `der Stein` / `der Sand` / `der Wagen` | 車は「`der Wagen`」イメージで男性 ※**例外 `das Auto`(車そのもの)** |

> **飲み物は全部 der ではない**:`der Saft`(ジュース)`der Kaffee`(コーヒー)は男性だが、`das Wasser`(水)`das Bier`(ビール)は中性。やはり1語ずつ。

### 語尾で決まるグループ

語尾(接尾辞)は意味より強い手がかりになる。

| 語尾 | 例(独) | 意味 |
|---|---|---|
| **`-ich`** | `der Teppich` / `der Teich` / `der Rettich` | カーペット / 池 / 大根 |
| **`-ig`** | `der Honig` / `der König` | はちみつ / 王様 |
| **`-ling`** | `der Schmetterling` / `der Lehrling` | 蝶 / 弟子 |
| **`-er`**(人・道具) | `der Kugelschreiber` / `der Wecker` / `der Fahrer` / `der Drucker` | ボールペン / 目覚まし時計 / 運転手 / プリンター |
| **`-ismus`** | `der Realismus` / `der Optimismus` | 現実主義 / 楽観主義 |
| **`-ist`** | `der Realist` / `der Kommunist` / `der Polizist` | 現実主義者 / 共産主義者 / 警察官 |

> **`-er` の例外に注意**:`-er` は男性が多いが、`das Zimmer`(部屋)`das Wasser`(水)は中性、`die Butter`(バター)`die Mutter`(母)は女性。

## ♀ 女性名詞(die)

### 意味で決まるグループ

| グループ | 例(独) | 意味 |
|---|---|---|
| ① 生物的に女性の人 | `die Frau` / `die Mutter` / `die Tochter` / `die Schwester` / `die Oma` / `die Tante` / `die Freundin` | 女性 / 母 / 娘 / 姉妹 / 祖母 / おば / 女友達 ※**例外 `das Mädchen`(少女)** |
| ② 職業(女性) — 男性形 + `-in` | `die Lehrerin` / `die Studentin` / `die Pilotin` / `die Politikerin` / `die Verkäuferin` / `die Köchin` / `die Youtuberin` | 女性が就くと語尾に `-in`(`-in` が付くので必ず女性) |
| ③ 多くの果物 | `die Kiwi` / `die Mango` / `die Ananas` / `die Banane` / `die Birne` | キウイ / マンゴー / パイナップル / バナナ / 洋梨 ※**例外 `der Apfel`(りんご)・`der Pfirsich`(桃)** |
| ④ 点数・数字(名詞化) | `die Eins` / `die Zwei` | 1点 / 2点(成績の数字) |
| ⑤ バイクのブランド | `die BMW` / `die Honda` / `die Kawasaki` | バイクは「`die Maschine`」イメージで女性(※**車**のブランドは `der`) |

> **`das Mädchen`(少女)はなぜ中性?** 生物的には女性だが、語尾 `-chen` が付くと**語尾のルールが優先**されて中性になる(後述)。「意味 < 語尾」の代表例。

### 語尾で決まるグループ

女性名詞は**語尾の手がかりが特に多い**。これが女性が約半数を占める理由。**以下の語尾はほぼ例外なく女性。**

| 語尾 | 例(独) | 意味 |
|---|---|---|
| **`-ung`** | `die Erinnerung` / `die Leistung` / `die Wohnung` / `die Zeitung` / `die Prüfung` | 思い出 / 成績 / 住居 / 新聞 / 試験 |
| **`-heit`** | `die Kindheit` / `die Gesundheit` / `die Freiheit` | 子供時代 / 健康 / 自由 |
| **`-keit`** | `die Möglichkeit` / `die Schwierigkeit` / `die Krankheit` | 可能性 / 困難 / 病気 |
| **`-schaft`** | `die Freundschaft` / `die Landschaft` / `die Mannschaft` | 友情 / 風景 / チーム |
| **`-ei`** | `die Bäckerei` / `die Metzgerei` | パン屋 / 肉屋 |
| **`-e`**(多くが女性) | `die Woche` / `die Stunde` / `die Blume` / `die Farbe` | 週 / 時間 / 花 / 色 |
| **`-ik`** | `die Politik` / `die Fabrik` / `die Musik` | 政治 / 工場 / 音楽 |
| **`-ion`** | `die Information` / `die Region` / `die Situation` | 情報 / 地域 / 状況 |
| **`-tät`** | `die Universität` / `die Realität` / `die Qualität` | 大学 / 現実 / 品質 |

> **`-e` / `-ion` の例外**:`der Löwe`(ライオン)`der Name`(名前)`der Junge`(少年)は `-e` でも男性(主に「人・動物の男性」や n変化名詞)。`der Spion`(スパイ)は `-ion` でも男性(これも「人」だから)。

## ⬜ 中性名詞(das)

### 意味で決まるグループ

| グループ | 例(独) | 意味 |
|---|---|---|
| ① 国・都市 | `(das) Deutschland` / `(das) Japan` / `(das) Berlin` | 多くは中性。**ふだんは無冠詞**で使う ※例外 `die Schweiz`(スイス)・`der Irak`・`die Türkei`・`die USA`(複数) |
| ② 物質・金属 | `das Gold` / `das Silber` / `das Eisen` / `das Holz` / `das Glas` | 金 / 銀 / 鉄 / 木材 / ガラス ※例外 `die Bronze`(青銅)・`der Stahl`(鋼) |
| ③ 色・文字・音(名詞化) | `das Rot` / `das Blau` / `das A` / `das C` | 赤 / 青 / 文字のA / 音のド。色名・アルファベット・音名はほぼ中性 |
| ④ 不定詞の名詞化(〜すること) | `das Essen` / `das Leben` / `das Lernen` | 食べること(食事) / 生きること(人生) / 学ぶこと。動詞の不定詞をそのまま名詞にすると中性 |

### 語尾で決まるグループ

| 語尾 | 例(独) | 意味 |
|---|---|---|
| **`-chen`**(縮小形) | `das Mädchen` / `das Brötchen` / `das Hähnchen` | 少女 / 小型パン / チキン。**意味より語尾が優先** |
| **`-lein`**(縮小形) | `das Fräulein` / `das Büchlein` | お嬢さん / 小さな本 |
| **`-um`**(ラテン語系) | `das Datum` / `das Studium` / `das Museum` / `das Zentrum` / `das Praktikum` | 日付 / 学業 / 博物館 / 中心 / 実習 |
| **`-ment`** | `das Experiment` / `das Element` / `das Dokument` / `das Medikament` | 実験 / 要素 / 書類 / 薬 ※例外 `der Moment`(瞬間) |
| **`-nis`** | `das Geheimnis` / `das Erlebnis` / `das Ergebnis` | 秘密 / 体験 / 結果 ※例外 `die Kenntnis`(知識)・`die Erlaubnis`(許可) |
| **`-tum`** | `das Eigentum` / `das Altertum` / `das Wachstum` | 財産 / 古代 / 成長 ※例外 `der Irrtum`(誤り)・`der Reichtum`(富) |

> **`-um` の落とし穴**:中性になるのは**ラテン語由来の `-um`**(Datum, Museum…)。`der Baum`(木)`der Raum`(部屋・空間)`der Traum`(夢)は語尾 `-aum` のゲルマン系で**男性**。形が似ているが別物。
> **`-chen` ≠ `Kuchen`**:`das Mädchen` は縮小形 `-chen` だが、`der Kuchen`(ケーキ)は縮小形ではないので**男性**。語尾の見た目に惑わされない。

## 🧾 まとめ(早見表)

### 意味カテゴリーで当たりをつける

| 男性 `der` が多い | 女性 `die` が多い | 中性 `das` が多い |
|---|---|---|
| 男性の人・職業(男) | 女性の人・職業(女, `-in`) | 国・都市 |
| 曜日・時間帯 | 果物 | 物質・金属 |
| 月・季節・方角 | 点数 | 色・文字・音 |
| 風・天候 | バイクのブランド | 不定詞の名詞化(〜すること) |
| 酒・車のブランド・石 | | |

### 語尾で当たりをつける

| → 男性 `der` | → 女性 `die` | → 中性 `das` |
|---|---|---|
| `-ich` `-ig` `-ling` | `-ung` `-heit` `-keit` | `-chen` `-lein` |
| `-er`(人・道具) | `-schaft` `-ei` | `-um`(ラテン系) |
| `-ismus` `-ist` | `-e` `-ik` `-ion` `-tät` | `-ment` `-nis` `-tum` |

> **使い方:語尾 → 意味カテゴリー → それでも分からなければ暗記**。語尾の手がかりは意味より強い(`das Mädchen` のように語尾が勝つ)。

## 📒 ついでに覚える A1–A2 名詞(冠詞つき)

ここまでの見分け方を、よく出る基本単語で固めておこう。**冠詞ごと声に出す**のがコツ。

### 男性 `der`

| 語 | 意味 | 語 | 意味 |
|---|---|---|---|
| `der Computer` | コンピューター | `der Koffer` | スーツケース |
| `der Fehler` | 間違い | `der Schüler` | 生徒 |
| `der Drucker` | プリンター | `der Hunger` | 空腹 |
| `der Traum` | 夢 | `der Raum` | 部屋・空間 |

### 女性 `die`

| 語 | 意味 | 語 | 意味 |
|---|---|---|---|
| `die Wohnung` | 住居 | `die Prüfung` | 試験 |
| `die Einladung` | 招待(状) | `die Rechnung` | 請求書 |
| `die Entschuldigung` | ごめんなさい | `die Erfahrung` | 経験 |
| `die Adresse` | 住所 | `die Fahrkarte` | 切符 |

### 中性 `das`

| 語 | 意味 | 語 | 意味 |
|---|---|---|---|
| `das Datum` | 日付 | `das Studium` | (大学の)学業 |
| `das Museum` | 博物館 | `das Zentrum` | 中心 |
| `das Praktikum` | 実習 | `das Brötchen` | 小型パン |
| `das Mädchen` | 女の子 | `das Hähnchen` | チキン |

## ❌ よくある間違い・落とし穴

| ありがちなミス | 正しくは | 理由 |
|---|---|---|
| `die Mädchen`(女の子=女性だから) | `das Mädchen` | `-chen` は語尾が勝って中性 |
| `das Baum`(`-um` だから中性?) | `der Baum` | ラテン系 `-um` ではなく `-aum`(ゲルマン系)→ 男性 |
| `das Kuchen`(`-chen` だから?) | `der Kuchen` | `Kuchen` は縮小形ではない。ただの単語で男性 |
| `der BMW`(バイク)/ `die BMW`(車) | 車=`der BMW`・バイク=`die BMW` | 車は `der Wagen`、バイクは `die Maschine` のイメージ |
| 意味だけ覚えて性は後回し | 最初から `der/die/das` 付き | 後から性だけ覚え直すのは二度手間 |

> **最後にもう一度**:性に深入りして「なぜ?」と悩むより、**冠詞つきで単語を山ほど浴びる**のが近道。感覚ができてから、このページの見分け方を「答え合わせ」として読み返すと、ぐっと定着する。
