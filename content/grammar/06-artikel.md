# ドイツ語文法 06 — 定冠詞と不定冠詞(使い分け)

[01](01-personalpronomen-sein.md)〜[05 名詞の格変化](05-nomen-kasus.md)に続く第6回。[05](05-nomen-kasus.md)で `der/die/das`(**定冠詞**)の格変化をやった。今回はもう一つの冠詞 **不定冠詞 `ein/eine`** を覚え、そして本題の **「どっちを使うか」** を見分ける。**冠詞の使い分けは英語の `the` / `a` にもそのまま応用できる。**

- ゴール:① 定冠詞=「**その**(特定)」/ 不定冠詞=「**ある一つの**(不特定・数の1)」の意味をつかむ ② **不定冠詞 `ein-` の格変化**を覚える ③ **定冠詞を使う場面・不定冠詞を使う場面**を13例で見分ける ④ **冠詞を付けない**(無冠詞)場合を知る
- いちばん大事な心構え:ドイツ語は会話でも**名詞の前にほぼ必ず冠詞が要る**。日本語の「りんごが食べたい」はそのままでも文になるが、ドイツ語は `Ich will einen Apfel essen.` のように **冠詞なしでは文が完成しない**。だから「名詞を出す→どの冠詞?」を反射でできるようにする。

## 🎯 大原則 — 2種類の冠詞

| 冠詞 | ドイツ語名 | 形 | 日本語の目安 | 中身 |
|---|---|---|---|---|
| **定冠詞** | bestimmter Artikel | `der / die / das` | **その**〜 | **特定**・もう何を指すか分かっている |
| **不定冠詞** | unbestimmter Artikel | `ein / eine` | **ある**〜・**1つの**〜 | **不特定**・初めて出す/どれでもいい/数の「1」 |

- `bestimmt` = 特定の、はっきりした。`unbestimmt` = ぼんやりした、不特定の。
- 不定冠詞 `ein` はそもそも数の **「1」**(英語 *one*)と同じ語。だから **不定冠詞に複数形は無い**(「1つの」だから当然)。複数で「いくつかの〜」を言いたいときは**無冠詞**にする。

```
Da ist ein Mann.   → そこに(ある一人の)男がいる   … 初登場・不特定 → 不定冠詞
Der Mann ist groß. → その男は背が高い             … もう特定済み   → 定冠詞
```

## 📊 不定冠詞 `ein-` の格変化

[05](05-nomen-kasus.md) の定冠詞表と**同じ場所に同じ語尾**が付く。ラクをするコツは「**`ein` を `der` と同じだと思って語尾を真似る**」こと。

| 格 | maskulin(男性) | feminin(女性) | neutral(中性) | Plural(複数) |
|---|---|---|---|---|
| **1格** Nominativ(が) | **ein** Mann | **eine** Frau | **ein** Kind | —(無し) |
| **2格** Genitiv(の) | **eines** Mann**es** | **einer** Frau | **eines** Kind**es** | — |
| **3格** Dativ(に) | **einem** Mann | **einer** Frau | **einem** Kind | — |
| **4格** Akkusativ(を) | **einen** Mann | **eine** Frau | **ein** Kind | — |

### 定冠詞と並べると規則が見える

| 格 | 男性 定 → 不定 | 女性 定 → 不定 | 中性 定 → 不定 |
|---|---|---|---|
| 1格 | der → **ein** | die → eine | das → **ein** |
| 2格 | des → eines | der → einer | des → eines |
| 3格 | dem → einem | der → einer | dem → einem |
| 4格 | den → einen | die → eine | das → **ein** |

> **語尾がゼロになるのは3か所だけ**:**男性1格 `ein`・中性1格 `ein`・中性4格 `ein`**。ここは `der/das` のような語尾が付かず、むき出しの `ein`。それ以外は定冠詞と同じ語尾(`-es / -em / -e / -en / -er`)。
> **名詞のおしりの変化は[05](05-nomen-kasus.md)と同じ**:男性・中性の2格は名詞に `-(e)s`(`eines Mannes`)。複数3格の `-n` は不定冠詞には複数が無いので関係しない。

## 🧭 本題 — 定冠詞・不定冠詞の使い分け(13例)

同じ「本」でも、状況で `das Buch`(その本)か `ein Buch`(ある本)かが変わる。**「聞いた相手がどの本か特定できるか?」** が分かれ目。

### 定冠詞 `der/die/das` を使う4つの場面

| # | 場面 | 例 | 意味 |
|---|---|---|---|
| 1 | **特定済み・それについて話す** | **Das** Buch ist von Haruki Murakami. | その本は村上春樹の作だ |
| 4 | **一度出た名詞の再言及(2回目)** | (初:Da liegt ein Buch.)→ **Das** Buch ist neu. | その本は新しい |
| 7 | **世界に一つしかない** | **Die** Erde ist rund. | 地球は丸い |
| 8 | **だれもが分かる一般常識** | **Das** Eis ist kalt. | 氷は冷たい |

ほかに:**固有名で完全に特定**(`Das ist **der** Hauptbahnhof.`=これは(あの)中央駅だ)、**恋人**(後述10)。

### 不定冠詞 `ein/eine` を使う4つの場面

| # | 場面 | 例 | 意味 |
|---|---|---|---|
| ① | **数の「1」を示す** | Ich habe **einen** Bruder. | 兄が1人いる |
| ②(2・3・5) | **特定の1つだが“それ”が話題でない**(存在「〜がある」) | **Ein** Buch liegt unter der Tasche. / Hier liegt **ein** Buch. / Das ist **ein** Bahnhof. | かばんの下に本がある/ここに本がある/これは駅だ |
| ③(11) | **不特定の1つ**(まだ誰/どれか決まっていない) | Ich möchte irgendwann **eine** Freundin. | いつか彼女が欲しい |
| ④(9) | **カテゴリの一員**(複数いるうちの1人) | Anna ist **eine** Freundin von Kevin. | アンナはケビンの(友達の一人) |

> **②がいちばん難しい**:目の前にある特定の物でも、**その物の名前・中身が話題でなく「(何かが)そこにある」状態だけ**を言うなら不定冠詞。例3「ここに本がある」は、本の題名はどうでもよく「本が1冊ある」ことが要点 → `ein Buch`。

### 注意:恋人は「定冠詞」(9 vs 10)

ドイツ語に「彼氏・彼女」専用の語はなく、`Freund/Freundin`(友達)で表す。**冠詞で恋人かただの友達かが変わる。**

| 例 | 冠詞 | 意味 |
|---|---|---|
| Anna ist **eine** Freundin von Kevin. | 不定 | アンナはケビンの**友達(の一人)** |
| Julia ist **die** Freundin von Leon. | 定 | ユリアはレオンの**恋人**(ただ一人=特定) |

> 間違えると誤解を招く。「恋人」は世界にその人ただ一人=特定 → **定冠詞 `die Freundin`**。

### 初出は不定 → 再言及は定(物語の基本)

| 順 | 例 | 冠詞 |
|---|---|---|
| 初めて出す | **Ein** Mann kommt.(ある男が来る) | 不定 `ein` |
| 2回目以降 | **Der** Mann ist alt.(その男は年配だ) | 定 `der` |

英語と同じ(*A man comes. The man is old.*)。**英語の `a/the` の感覚がそのまま使える。**

## 🚫 冠詞を付けない場合(Nullartikel)

例外的に**冠詞ゼロ**で名詞を出す場面がある。

| 種類 | 例 | メモ |
|---|---|---|
| **不可算(数えない)** | Ich trinke **Wasser**. / Ich esse **Reis**. | 雨・粉・米・飲み物など。[04](04-nomen-plural.md)の「単数のみ名詞」と重なる |
| **職業**(sein/werden の後) | Ich bin **Lehrer**. / Sie wird **Ärztin**. | 「私は(ある)教師だ」とは言わない |
| **国籍** | Ich bin **Japaner**. | |
| **言語** | Ich lerne **Deutsch**. / Ich spreche **Englisch**. | |

> 自己紹介(`Ich bin Student. Ich komme aus Japan. Ich lerne Deutsch.`)は無冠詞だらけ。職業・国籍・言語はそのまま置く、と覚える。

### 補足:`ein` の否定は `kein-`

「1つも〜ない/〜ではない」は不定冠詞の否定 **`kein-`**。変化は **`ein-` と全く同じ**(`kein/keine/keinen/keinem…`)。ただし **`kein` には複数形 `keine` がある**(`ein` の“複数版”が `keine` だと考えると整理しやすい)。

- Ich habe **einen** Bruder. → Ich habe **keinen** Bruder.(兄はいない)
- Ich habe **keine** Geschwister.(きょうだいはいない/複数)

## 🧾 まとめ(早見表)

### どっちを使う?(判定フロー)

1. **数えない・職業・国籍・言語** → **無冠詞**。
2. **聞き手がどれか特定できる?**
   - **できる**(特定済み/再言及/世界に一つ/一般常識/固有名/恋人)→ **定冠詞 `der/die/das`**。
   - **できない**(初登場/どれでもいい/数の1/存在「〜がある」/カテゴリの一員)→ **不定冠詞 `ein/eine`**(複数なら無冠詞)。

| → 定冠詞(その・特定) | → 不定冠詞(ある一つ・不特定) |
|---|---|
| 特定済みで話題にしている | 初めて出す |
| 一度出た再言及(2回目) | 数の「1」 |
| 世界に一つ(die Erde) | 特定の1つだが話題でない(存在文) |
| 一般常識(das Eis ist kalt) | 不特定の1つ(いつか彼女が…) |
| 恋人(die Freundin) | カテゴリの一員(eine Freundin) |

> **英語に置き換えると速い**:定冠詞 ≒ `the`、不定冠詞 ≒ `a/an`、無冠詞 ≒ 英語でも無冠詞(*I drink water. I am a teacher* ※英語は職業に a が要る点だけ違う)。

## ❌ よくある間違い・落とし穴

| ありがちなミス | 正しくは | 理由 |
|---|---|---|
| 名詞を冠詞なしで置く(Ich will Apfel essen.) | Ich will **einen** Apfel essen. | 数える名詞は冠詞が要る(不可算・職業等を除く) |
| 男性1格に `einer`(der の真似で語尾) | **ein** Mann | 男性1格・中性1格/4格は語尾ゼロの `ein` |
| 中性4格 `eines`/`einen` | **ein** Kind | 中性は1格=4格でむき出しの `ein` |
| Ich bin **ein** Student.(英語の a につられる) | Ich bin **Student**. | 職業は無冠詞(独語) |
| Julia ist **eine** Freundin von Leon.(恋人なのに) | Julia ist **die** Freundin von Leon. | 恋人=ただ一人=特定 → 定冠詞 |
| 「いつか彼女が欲しい」を `die Freundin` | Ich möchte irgendwann **eine** Freundin. | まだ誰か未定 → 不特定 → 不定冠詞 |
| 複数に `ein`(eine Bücher) | 無冠詞(**Bücher**)/ 否定は **keine** Bücher | 不定冠詞に複数は無い |

> **最後にもう一度:** 「①数えない/職業・国籍・言語=無冠詞 → ②聞き手が特定できれば `der/die/das`、できなければ `ein/eine`(複数は無冠詞)」。`ein-` の語尾は **3か所(男1格・中1格・中4格)だけゼロ**、あとは `der-` と同じ。迷ったら**英語の the / a に置き換えて**当たりをつける。
