# Sprechen A2 — 最短合格のための「丸暗記＆音読」教材

Goethe-Zertifikat **A2 の Sprechen(口述)** に最短で受かるための、**そのまま覚えれば使える文** を集めた音読練習教材。
全体の試験概要は [`goethe-a2.md`](../../content/exam-guide/exam-info/goethe-a2.md)、問題形式は [`a2-question-types.md`](../../content/exam-guide/question-types/a2-question-types.md) を参照。

> **このフォルダの考え方**: A2 の Sprechen は「ペア試験・約15分・形式は固定」。出る型が決まっているので、**Redemittel(定型表現)を口が勝手に動くまで音読**すれば確実に点が取れる。完璧な文法より「**つっかえず・はっきり・反応できる**」が採点上ずっと重要。

---

## 🎯 試験の中身(これだけ把握すればいい)

| | 内容 | 自分がやること | 配点の核 |
|---|---|---|---|
| **Teil 1** | 相手に質問する／質問に答える | カード4枚の語(例 `Beruf?`)から質問を作る → 交代で答える | 質問が作れるか・答えられるか |
| **Teil 2** | 自分・自分の生活について話す | お題1つ＋ヒント語4つを見て、自分のことを**まとまって話す** | 1人で30〜60秒、話を続けられるか |
| **Teil 3** | 相手と一緒に計画する | カレンダーを見て**都合の合う日時・場所を決める** | 提案・同意・断り・代案ができるか |

- 形式: **2人1組**(相手も受験者)。試験官2名。所要 **約15分**。
- 配点: Sprechen は **25点**。合格には Sprechen 単体で **15点以上**(かつ全体60点以上、筆記45点以上)。
- **準備時間は約20秒だけ**(各 Teil の前)。だから「考えてから話す」では間に合わない → **覚えた型を出す**。

### 試験官が実際に言うこと(公式 Modellsatz より)

本番でこの通りの司会が入る。心の準備になる:

> 「Herzlich willkommen zum Goethe-Zertifikat A2. … **Wie heißen Sie? Woher kommen Sie? Wo lernen Sie Deutsch?**」(最初の軽い自己紹介)
> 「Diese Prüfung hat drei Teile. **Teil 1 ist ein Gespräch.** … Nehmen Sie vier Karten. **Wer möchte beginnen?**」
> 「Danke. Das war Teil 1. **In Teil 2 erzählen Sie uns etwas über sich.** Sie bekommen ein Aufgabenblatt. **Erzählen Sie.**」
> 「Vielen Dank. Das war Teil 2. **In Teil 3 planen Sie etwas zusammen.**」
> 「Vielen Dank. Wir sind am Ende der Prüfung. Auf Wiedersehen!」

→ つまり試験開始直後に **名前・出身・「どこでドイツ語を学んでいるか」** を必ず聞かれる。ここは [`00-kern-redemittel.md`](./docs/00-kern-redemittel.md) の冒頭で固める。

## 🧮 何で採点されるか(公式 Bewertungskriterien Sprechen)

A(満点)〜E(0点)の5段階。3つの観点で見られる:

1. **Aufgabenerfüllung(課題達成)**
   - *Sprachfunktion*: 質問・依頼・提案など、その場面に必要な機能を出せたか
   - *Interaktion*: 相手の発言に**反応**し、会話が成立しているか(← Teil 3 で重要)
   - *Register*: 相手に合った言い方(du/Sie、丁寧さ)
2. **Sprache(言語)**: 語彙・文構造の**幅**と**正確さ**(多少の間違いは減点されない)
3. **Aussprache(発音)**: 文の抑揚・アクセント・個々の音。**伝われば OK**、完璧不要。

> 取りこぼし注意: **黙る＝0点に直結**(`Gesprächsanteil nicht bewertbar`)。分からなくても何か言う。沈黙より「`Können Sie das bitte wiederholen?`」。

## 🗾 日本人がやりがちな発音ミス(先に直すと得)

| 綴り | 正しい音 | ありがちな間違い |
|---|---|---|
| `w` | **v**(ヴ) | ワ行で読む(Wohnung=ヴォーヌング) |
| `v` | **f**(フ) | ヴで読む(Vater=ファーター) |
| `z` | **ts**(ツ) | ズで読む(Zeit=ツァイト) |
| `s`+母音 | **z**(濁る) | sの清音(sagen=ザーゲン) |
| `ei` | **アイ** | エイ(mein=マイン) |
| `ie` | **イー(長音)** | イエ(Liebe=リーベ) |
| `eu / äu` | **オイ** | エウ(Freund=フロイント) |
| `ch`(a,o,u の後) | **ハ/ホ(喉)** | クで止める(auch=アオホ) |
| `ü / ö` | 唇を丸めた イ/エ | u/o のまま |
| `r`(語末) | **ア(弱く)** | 巻き舌を強く(Vater=ファータ) |
| `st / sp`(語頭) | **シュト/シュプ** | スト/スプ(Straße=シュトラーセ) |

## 📚 ファイル構成(練習する順番)

| # | ファイル | 中身 | 使い方 |
|---|---|---|---|
| 0 | [`mein-steckbrief.md`](./docs/mein-steckbrief.md) | **自分のプロフィール台本**(名前・仕事・趣味…) | **最初にここを埋める**。全Teilの答えの土台 |
| 1 | [`00-kern-redemittel.md`](./docs/00-kern-redemittel.md) | 全Teil共通の万能フレーズ | 毎日音読。最優先で丸暗記 |
| 2 | [`teil-1-fragen-antworten.md`](./docs/teil-1-fragen-antworten.md) | カード語ごとの「質問」と「答え」 | 質問形と答えをセットで覚える |
| 3 | [`teil-2-ueber-mich.md`](./docs/teil-2-ueber-mich.md) | お題ごとの**丸暗記モノローグ** | お題1つ＝1分の話を暗唱 |
| 4 | [`teil-3-zusammen-planen.md`](./docs/teil-3-zusammen-planen.md) | 計画対話の定型＋模擬対話 | 提案→断り→代案→合意の型を反復 |

各ファイルは **`| 🗣️ Deutsch | 🇯🇵 日本語 |`** の対訳表で統一。
**左を音読 → 右で意味確認**。慣れたら右を隠して言えるか確認。

### 推奨ルーティン(読みの練習)
1. まず [`mein-steckbrief.md`](./docs/mein-steckbrief.md) を自分の情報で埋める。
2. 毎日 [`00-kern-redemittel.md`](./docs/00-kern-redemittel.md) を1回通し音読(5分)。
3. Teil 1〜3 を1ファイルずつ、**声に出して**読む。スマホで録音して聞き返す。
4. 右の日本語を隠し、ドイツ語が口から出るか毎週チェック。
