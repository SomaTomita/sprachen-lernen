# 00 — 核となる Redemittel(全 Teil 共通の万能フレーズ)

ここが**最優先**。この30〜40文を口が勝手に動くまで音読すれば、どのお題が来ても会話が回る。
**左を音読 → 右で意味確認**。

---

## 1. 試験の始め:挨拶と自己紹介(ウォームアップ)

試験官に最初に必ず聞かれる。即答できるように。

| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| Guten Tag! / Hallo! | こんにちは! |
| Ich heiße **Soma Tomita**. | トミタ ソウマと申します。 |
| Ich komme aus **Japan**, aus **Osaka**. | 日本の大阪から来ました。 |
| Ich lerne Deutsch **in einer Sprachschule** / **online**. | 語学学校で／オンラインでドイツ語を学んでいます。 |
| Ich lerne Deutsch, weil ich **die Sprache mag** / **in Deutschland arbeiten möchte**. | この言語が好きなので／ドイツで働きたいので学んでいます。 |
| Freut mich! | はじめまして!(よろしく) |

---

## 2. 困ったとき:聞き返す・時間を稼ぐ(超重要)

**黙ると0点に近づく**。分からなくても必ずこれで繋ぐ。

| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| Wie bitte? | もう一度お願いします?(え?) |
| Können Sie das bitte **wiederholen**? | もう一度言ってもらえますか? |
| Können Sie das bitte **noch einmal sagen**? | もう一度言ってもらえますか? |
| Entschuldigung, ich habe Sie nicht **verstanden**. | すみません、聞き取れませんでした。 |
| Können Sie bitte **langsamer** sprechen? | もう少しゆっくり話してもらえますか? |
| Wie heißt das auf Deutsch? | これはドイツ語で何と言いますか? |
| Was bedeutet **„…"**? | 「…」はどういう意味ですか? |
| **Moment, bitte.** / **Lassen Sie mich kurz überlegen.** | 少々お待ちを。／少し考えさせてください。 |
| **Also …** / **Na ja …** / **Wie soll ich sagen …** | ええと…／まあ…／何と言うか… |

---

## 3. 意見・感想を言う(Teil 2・3 で多用)

| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| Ich finde, dass … | 私は…だと思います。 |
| Ich glaube, … | …だと思います。 |
| Meiner Meinung nach … | 私の考えでは… |
| Ich mag **…** (sehr). | …が(とても)好きです。 |
| Ich mag **…** nicht so. | …はあまり好きではありません。 |
| Das finde ich **gut / interessant / wichtig**. | それは良い／面白い／大事だと思います。 |
| Für mich ist **…** wichtig. | 私にとって…は大切です。 |

---

## 4. 文をつなぐ「接着剤」(これで話が長くなる)

A2 で点が伸びるかは「文をつなげるか」。最低限この6個。

| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **und** | そして |
| **aber** | でも |
| **oder** | または |
| **denn** … / …, **weil** … | なぜなら…(理由) |
| Ich bleibe zu Hause, **weil** ich müde **bin**. | 疲れているので家にいます。(weil は動詞が文末) |
| …, **deshalb** … | だから…(主語の前で動詞が来る:deshalb gehe ich …) |
| **zuerst** …, **dann** …, **danach** …, **am Ende** … | まず…、それから…、その後…、最後に… |
| **zum Beispiel** … | 例えば… |
| **manchmal / oft / immer / nie** | 時々／よく／いつも／決して〜ない |

---

## 5. 賛成・反対・提案(Teil 3 の心臓部・ここでも先取り)

| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **Gute Idee!** / Das ist eine gute Idee. | いいですね!／良い考えです。 |
| **Einverstanden!** / **Abgemacht!** | 賛成!／決まりですね! |
| Ja, **das passt** (mir gut). | はい、それで都合がいいです。 |
| **Wollen wir …?** / **Können wir …?** | 一緒に…しませんか?／…できますか? |
| **Vielleicht** … / **Vielleicht ist es besser, wenn …** | たぶん…／…の方がいいかもしれません。 |
| Das geht **leider nicht**. | 残念ながらそれは無理です。 |
| Tut mir leid, aber **ich habe da keine Zeit**. | すみません、その時間は空いていません。 |

> Teil 3 専用のもっと細かい型は [`teil-3-zusammen-planen.md`](./teil-3-zusammen-planen.md)。

## 6. 試験の終わり

| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| Vielen Dank! | ありがとうございました! |
| Das war schön. | 楽しかったです。 |
| Auf Wiedersehen! / Tschüss! | さようなら!／じゃあね! |

- [ ] 接着剤6個(und/aber/weil/deshalb/dann/zum Beispiel)で文を伸ばせる
