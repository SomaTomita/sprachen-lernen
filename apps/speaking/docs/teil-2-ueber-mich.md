# Teil 2 — Über mich erzählen(自分について話す)

## 形式のおさらい
- カードに **お題1つ＋ヒント語4つ**(例: お題「Was machen Sie mit Ihrem Geld?」/ ヒント `Kleidung` `Miete` `Sparen` `Reisen`)。
- 試験官が「**Erzählen Sie.**」と言ったら、**1人で30〜60秒**まとまって話す。
- ヒント語4つ全部に触れると高得点。話の後、試験官が**追加質問を1〜2個**してくる。
- 相手の発表中は聞き役。終わったら交代。

> 戦略: **お題ごとに「丸暗記モノローグ」を1本**用意。本番は固有名・数字を差し替えるだけ。
> 各モノローグは下の **万能の型**(導入→ヒント1→2→3→4→締め)で作ってある。

---

## 🧩 万能の型(どのお題でもこれに乗せる)

| 役割 | 使う言い回し |
|---|---|
| 導入 | **Also, zum Thema „…" möchte ich erzählen, dass …** / **Bei mir ist das so:** |
| 列挙 | **Zuerst …**, **Außerdem …**, **Dann …**, **Und manchmal …** |
| 理由 | **…, weil …** / **…, denn …** |
| 例 | **Zum Beispiel …** |
| 締め | **Das ist für mich wichtig.** / **So ist das bei mir.** |

---

## 💶 お題1: Was machen Sie mit Ihrem Geld?(お金の使い方)
**ヒント:** `Kleidung` `Lebensmittel / Miete` `Sparen` `Reisen`

| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| Also, ich gebe mein Geld für verschiedene Dinge aus. | ええと、私はお金をいろいろなものに使います。 |
| Zuerst zahle ich jeden Monat die **Miete**, das ist ziemlich teuer. | まず毎月家賃を払います、けっこう高いです。 |
| Dann kaufe ich **Lebensmittel**, ich koche gern zu Hause. | それから食料品を買います、家で料理するのが好きです。 |
| Für **Kleidung** gebe ich nicht so viel Geld aus. | 服にはあまりお金を使いません。 |
| Jeden Monat **spare** ich auch ein bisschen. | 毎月少し貯金もします。 |
| Ich spare, **weil** ich nächstes Jahr **reisen** möchte. | 来年旅行したいので貯金しています。 |
| Reisen ist mein größtes Hobby. So ist das bei mir. | 旅行が一番の趣味です。私はそんな感じです。 |
