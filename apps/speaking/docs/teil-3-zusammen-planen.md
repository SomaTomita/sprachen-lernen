# Teil 3 — Gemeinsam etwas planen(一緒に計画する)

## 形式のおさらい
- 相手と**一緒に1つのことを計画**する。多くは「**都合の合う日時を決める**」。
- 各自に**カレンダー(予定表)**が配られ、空いている時間を探して合わせる。
- 公式お題の例: 「**Ihr Freund Patrick hat Geburtstag. Sie möchten ein Geschenk für ihn kaufen. Finden Sie einen Termin.**」(友人パトリックの誕生日。プレゼントを買いに行く日を決める。)
- **採点の核は Interaktion(やり取り)**: 提案 → 相手が断る/受ける → 代案 → 合意、の**往復**ができるか。一方的に話すと×。

> 戦略: 下の **4ステップの型**(提案→反応→代案→合意)を覚え、模擬対話を**1人2役**で音読。
> 相手が「無理」と言う前提で、**代案を出す練習**が一番大事。

---

## 🔁 4ステップの型(これを回すだけ)

| ステップ | 役割 | 代表フレーズ |
|---|---|---|
| ① 提案する | Vorschlag | **Wollen wir am … treffen?** |
| ② 反応する | Reaktion | (OK)**Ja, das passt.** /(NG)**Da kann ich leider nicht.** |
| ③ 代案を出す | Alternative | **Geht es vielleicht am …?** |
| ④ 合意する | Einigung | **Gut, dann treffen wir uns am …. Abgemacht!** |

## 📇 Redemittel 一覧(丸ごと暗記)

### ① 提案する(Vorschläge machen)
| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **Ich habe eine Idee:** … | 考えがあります:… |
| **Wollen wir** zusammen ein Geschenk kaufen? | 一緒にプレゼントを買いませんか? |
| **Können wir** uns am Samstag treffen? | 土曜に会えますか? |
| **Treffen wir uns** am Freitag um drei? | 金曜の3時に会いましょうか? |
| **Wie wäre es** am Sonntagnachmittag? | 日曜の午後はどうですか? |
| **Was hältst du davon, wenn** wir um vier gehen? | 4時に行くのはどう思う? |
| **Hast du am Samstag Zeit?** | 土曜は時間ある? |
| **Was hast du am Wochenende vor?** | 週末は何か予定ある? |

### ② 賛成・受ける(Zustimmen)
| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **Ja, gerne!** | はい、喜んで! |
| **Das ist eine gute Idee.** | いい考えですね。 |
| **Ja, das passt mir gut.** | はい、それで都合がいいです。 |
| **Ja, das geht.** / **Kein Problem.** | はい、大丈夫です。／問題ありません。 |
| **Einverstanden!** / **Abgemacht!** | 賛成!／決まり! |
| **Super, machen wir das so.** | いいね、そうしましょう。 |

### ③ 断る＋理由(Ablehnen + Begründung)
**断りっぱなしはダメ。必ず理由＋代案とセット。**
| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **Tut mir leid, aber** da kann ich nicht. | ごめん、その時は無理です。 |
| Am Samstag **geht es leider nicht**. | 土曜は残念ながら無理です。 |
| Da **habe ich keine Zeit, weil** ich arbeiten muss. | 仕事があるのでその時間はありません。 |
| **Das passt mir leider nicht so gut.** | あいにく都合が良くないです。 |
| Am Vormittag **bin ich beschäftigt**. | 午前中は忙しいです。 |

### ④ 代案を出す(Alternative vorschlagen)
| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **Geht es vielleicht am Sonntag?** | 日曜はどうですか? |
| **Können wir uns später treffen, um fünf?** | もっと遅く、5時に会えますか? |
| **Wie wäre es stattdessen am Nachmittag?** | 代わりに午後はどうですか? |
| **Vielleicht ist es besser, wenn** wir am Freitag gehen. | 金曜に行く方がいいかもしれません。 |
| **Dann lass uns** am Samstagabend treffen. | じゃあ土曜の夜に会いましょう。 |

### ⑤ 場所・詳細を決める(Wo? / Was?)
| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **Wo treffen wir uns?** | どこで会う? |
| **Treffen wir uns am Bahnhof** / **vor dem Kaufhaus.** | 駅で／デパートの前で会いましょう。 |
| **Was kaufen wir** für Patrick? | パトリックに何を買う? |
| **Vielleicht ein Buch?** / Wie wäre es mit einem Buch? | 本とか?／本はどう? |
| **Ich finde ein Buch besser.** | 本の方がいいと思う。 |
| **Wie viel Geld geben wir aus?** | いくら使う? |

### ⑥ 合意して終わる(Einigung / Abschluss)
| 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|
| **Gut, dann treffen wir uns am Samstag um drei.** | よし、土曜の3時に会いましょう。 |
| **Alles klar!** / **Abgemacht!** | 了解!／決まり! |
| **Dann bis Samstag!** | じゃあ土曜に! |
| **Ich freue mich!** | 楽しみです! |

## 🎭 模擬対話 1:プレゼントを買う(公式お題・パトリックの誕生日)

| 役 | 🗣️ Deutsch | 🇯🇵 日本語 |
|---|---|---|
| A | Patrick hat bald Geburtstag. **Wollen wir** zusammen ein Geschenk kaufen? | パトリックがもうすぐ誕生日。一緒にプレゼント買わない? |
| B | **Ja, gute Idee!** Wann hast du Zeit? | いいね!いつ空いてる? |
| A | **Geht es am Samstagvormittag?** | 土曜の午前はどう? |
| B | **Tut mir leid,** am Vormittag **geht es nicht,** ich habe einen Termin. | ごめん、午前は無理、予定があるんだ。 |
| A | **Kein Problem. Geht es vielleicht am Nachmittag, um vier?** | 大丈夫。じゃあ午後、4時はどう? |
| B | **Ja, vier Uhr passt mir gut.** Und was kaufen wir? | うん、4時で都合いいよ。で、何を買う? |
| A | **Wie wäre es mit einem Buch?** | 本はどう? |
| B | **Ich finde ein Buch gut.** Wo treffen wir uns? | 本いいね。どこで会う? |
| A | **Treffen wir uns vor dem Kaufhaus.** | デパートの前で会おう。 |
| B | **Abgemacht! Dann bis Samstag!** | 決まり!じゃあ土曜に! |

## 🎭 模擬対話 2:週末に一緒に出かける

| 役 | 🗣️ Deutsch | 🇯🇵 日本語 |

| B | Samstagabend **kann ich leider nicht, weil** ich arbeite. **Geht es am Sonntag?** | 土曜の夜は仕事で無理。日曜はどう? |

| B | **Wie wäre es um sieben?** | 7時はどう? |
| A | **Sieben Uhr ist super.** Wo treffen wir uns? | 7時いいね。どこで会う? |
| B | **Vor dem Kino. Abgemacht!** | 映画館の前で。決まり! |
