# 文法練習 (grammar-exercises)

`content/grammar/` の文法レッスンに対応した練習問題を解くオフラインアプリ。
穴埋め・表埋め・選択・書き換え・和訳（自己採点）を **その場で採点＋解説**。進捗は保存しない。

## 使い方
1. リポジトリ直下で `./serve.sh`。
2. ホームの「文法練習」カード、または `http://localhost:8000/apps/grammar-exercises/`。
3. レッスン（01 / 02）を選ぶ。各問「チェック」で正誤と解説。和訳は「答えを見る」で模範解答。
4. 独語の選択肢・正解・模範解答の横の**スピーカーボタン**をタップすると発音が鳴る（Web Speech API・端末のドイツ語音声。非対応端末では非表示）。
5. 解説を読み直したいときは各レッスンの「← 解説を読む」から。

## 開発
- テスト: `apps/grammar-exercises/` 直下で `node --test`（採点純関数＋データ整合）。
- 問題の足し方・データ形式・設計は `CLAUDE.md` と `docs/plans/` を参照。
- ビルド無し・依存なし・オフライン。素 HTML/CSS/JS（ES Modules）。
